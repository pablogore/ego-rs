# Contracts: Service SDK

Feature: 008-service-sdk | Date: 2026-06-08

## Contract 1: Service Contract Declaration

**File**: `crates/service-sdk/src/contract/service_contract.rs`

The `#[service]` attribute is used on both traits and structs with context-dependent behavior:

### On traits — Contract Metadata Generation

```rust
#[service(version = "1.0.0")]
pub trait OrderService {
    #[operation]
    async fn create_order(&self, cmd: CreateOrder) -> Result<OrderId, OrderError>;
}
```

Generates: `ServiceDescriptor`, `OperationDescriptor` for each `#[operation]` method.

### On structs — Dependency Metadata Generation

```rust
#[service]
pub struct OrderServiceImpl {
    orders: EntityRef<Order>,
    customers: ServiceRef<dyn CustomerService>,
}
```

Generates: `DependencyMetadata` (listing `EntityRef<Order>`, `ServiceRef<dyn CustomerService>`), `DependencyGraph`, and `Injectable` wiring metadata.

```rust
/// Trait implemented (by proc-macro) for every #[service] trait.
/// Users never implement this manually.
pub trait ServiceContract {
    fn type_id() -> TypeId where Self: Sized;
    fn name() -> &'static str where Self: Sized;
    fn version() -> ContractVersion where Self: Sized;
    fn descriptor() -> ServiceDescriptor where Self: Sized;
}
```

**Generated by**: `#[service(version = "1.0.0")]` proc-macro on trait or struct definitions.

## Contract 2: Descriptor Types

**File**: `crates/service-sdk/src/contract/descriptor.rs`

```rust
use std::any::TypeId;

/// Complete metadata for a service contract.
pub struct ServiceDescriptor {
    pub type_id: TypeId,
    pub name: &'static str,
    pub version: ContractVersion,
    pub operations: &'static [OperationDescriptor],
}

/// Metadata for a single operation.
pub struct OperationDescriptor {
    pub name: &'static str,
    pub input_type: TypeId,
    pub output_type: TypeId,
    pub category: OperationCategory,
    pub documentation: Option<&'static str>,
}

/// Categorization of an operation.
pub enum OperationCategory {
    /// Safe to retry; same input always produces same output.
    Idempotent,
    /// No side effects; can be called concurrently.
    ReadOnly,
    /// Produces state changes.
    Mutating,
}

/// Descriptor for a request or response type.
pub struct ContractDescriptor {
    pub type_id: TypeId,
    pub name: &'static str,
    pub fields: &'static [FieldDescriptor],
    pub documentation: Option<&'static str>,
}

/// Descriptor for a single field.
pub struct FieldDescriptor {
    pub name: &'static str,
    pub field_type: &'static str,
    pub required: bool,
    pub documentation: Option<&'static str>,
}

/// Semantic version identifier.
#[derive(Clone, PartialEq, Eq, PartialOrd, Ord)]
pub struct ContractVersion {
    pub major: u32,
    pub minor: u32,
    pub patch: u32,
}

impl std::fmt::Display for ContractVersion {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{}.{}.{}", self.major, self.minor, self.patch)
    }
}
```

## Contract 3: Service Registry API

```rust
use std::any::TypeId;
use std::sync::Arc;
use crate::contract::ContractVersion;
use crate::reference::ServiceRef;
use crate::error::RegistryError;

/// Central service registry — maps contracts to implementations.
pub struct ServiceRegistry { /* fields internal */ }

impl ServiceRegistry {
    /// Create empty registry.
    pub fn new() -> Self;

    /// Register a service implementation.
    /// `T` is the service contract trait (marked with #[service]).
    pub fn register<T: ServiceContract + Send + Sync + 'static>(
        &mut self,
        service: Arc<T>,
        name: Option<&str>,
        version: ContractVersion,
    ) -> Result<(), RegistryError>;

    /// Resolve a ServiceRef<T> handle.
    /// - `name`: optional logical name for multi-impl contracts
    /// - `version_constraint`: None = latest, Some = exact match
    pub fn resolve<T: ServiceContract + Send + Sync + 'static>(
        &self,
        name: Option<&str>,
        version_constraint: Option<ContractVersion>,
    ) -> Result<ServiceRef<T>, RegistryError>;

    /// Validate all dependencies are satisfied.
    pub fn validate(&self) -> Result<(), Vec<RegistryError>>;

    /// Merge another ServiceBundle into this registry.
    pub fn merge(&mut self, bundle: ServiceBundle) -> Result<(), RegistryError>;

    /// Add a global interceptor that applies to all invocations.
    pub fn add_interceptor(&mut self, interceptor: Box<dyn Interceptor>);
}
```

## Contract 4: ServiceRef<T> Invocation Handle

**File**: `crates/service-sdk/src/reference/service_ref.rs`

```rust
use std::sync::Arc;
use crate::contract::ServiceDescriptor;

/// Handle to a resolved service. Equivalent to EntityRef<T> at the service layer.
/// Wraps the implementation and applies interceptors, context, and tenant isolation.
pub struct ServiceRef<T: ?Sized> {
    service: Arc<dyn std::any::Any + Send + Sync>,
    descriptor: ServiceDescriptor,
    chain: InterceptorChain,
    _marker: std::marker::PhantomData<T>,
}

impl<T: ServiceContract + Send + Sync + 'static> ServiceRef<T> {
    /// Create a new ServiceRef.
    pub fn new(
        service: Arc<T>,
        descriptor: ServiceDescriptor,
        chain: InterceptorChain,
    ) -> Self;

    /// Access the service descriptor metadata.
    pub fn descriptor(&self) -> &ServiceDescriptor;
}
```

**Note**: `ServiceRef<T>` does not directly expose method calls. The concrete service trait methods are available through the trait itself (e.g., `service_ref.deref().create_order(cmd)`). The proc-macro generates a transparent wrapper that injects context + interceptors before delegation.

## Contract 5: Interceptor Trait

**File**: `crates/service-sdk/src/interceptor/interceptor.rs`

```rust
use async_trait::async_trait;
use crate::context::ServiceContext;
use crate::contract::OperationDescriptor;
use crate::error::DomainError;

/// Observes and instruments service invocations without modifying service code.
#[async_trait]
pub trait Interceptor: Send + Sync {
    /// Called before the service operation executes.
    async fn on_request(&self, ctx: &ServiceContext, op: &OperationDescriptor);

    /// Called after a successful operation result.
    async fn on_response(&self, ctx: &ServiceContext, op: &OperationDescriptor);

    /// Called after an operation error.
    async fn on_error(
        &self,
        ctx: &ServiceContext,
        op: &OperationDescriptor,
        error: &dyn DomainError,
    );
}

/// Ordered chain of interceptors. Called sequentially per hook.
pub struct InterceptorChain {
    interceptors: Vec<Box<dyn Interceptor>>,
}

impl InterceptorChain {
    pub fn new(interceptors: Vec<Box<dyn Interceptor>>) -> Self;

    pub async fn on_request(&self, ctx: &ServiceContext, op: &OperationDescriptor);
    pub async fn on_response(&self, ctx: &ServiceContext, op: &OperationDescriptor);
    pub async fn on_error(
        &self,
        ctx: &ServiceContext,
        op: &OperationDescriptor,
        error: &dyn DomainError,
    );
}
```

## Contract 6: DomainError Trait

**File**: `crates/service-sdk/src/error/domain_error.rs`

```rust
/// Common trait implemented by all service-specific error types.
/// Interceptors and transport adapters operate against this trait, not concrete types.
pub trait DomainError: std::error::Error + Send + Sync {
    /// Machine-readable error code (e.g., "ORDER_NOT_FOUND").
    fn code(&self) -> &str;

    /// Error classification.
    fn category(&self) -> ErrorCategory;
}

/// Framework-defined categories. Services map their errors to these.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ErrorCategory {
    /// Input validation failure.
    Validation,
    /// Resource not found.
    NotFound,
    /// Resource conflict (duplicate, version conflict).
    Conflict,
    /// Permission denied or unauthorized.
    Authorization,
    /// Business rule violation.
    BusinessRule,
    /// Runtime or infrastructure error.
    Infrastructure,
}
```

## Contract 7: ServiceContext API

**File**: `crates/service-sdk/src/context/context.rs`

```rust
use std::collections::HashMap;
use std::time::{Duration, Instant};
use uuid::Uuid;

tokio::task::task_local! {
    pub static SERVICE_CONTEXT: ServiceContext;
}

/// Invocation-scoped metadata. Propagated by the runtime.
pub struct ServiceContext {
    pub tenant_id: Option<String>,
    pub correlation_id: Uuid,
    pub trace_id: Uuid,
    pub deadline: Option<Instant>,
    pub timeout: Option<Duration>,
    pub metadata: HashMap<String, String>,
    pub cancellation: CancellationToken,
}

impl ServiceContext {
    /// Create a new context with generated correlation/trace IDs.
    pub fn new() -> Self;

    /// Set tenant ID.
    pub fn with_tenant(mut self, tenant_id: String) -> Self;

    /// Set deadline.
    pub fn with_deadline(mut self, deadline: Instant) -> Self;

    /// Access the current invocation context.
    /// Panics if called outside an invocation scope.
    pub fn current() -> &'static Self;

    /// Enter a scoped execution with this context.
    pub async fn scope<F, R>(self, future: F) -> R
    where
        F: std::future::Future<Output = R>;
}
```
